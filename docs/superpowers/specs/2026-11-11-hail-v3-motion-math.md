# 冰雹科普网页 v3：动画精修 + 公式排版

日期：2026-11-11
基于：`2026-11-11-hail-v2-design.md`（v2 规格仍然有效，本文件只写变更；冲突时以本文件为准）
用户原话：「已经相当好了，我想让画面的动画变得更精良，可爱，让各种数学公式看起来更专业。」

## 0. 范围

做两件事：**动画更精良、更可爱**；**数学公式用专业排版**。

不做（用户说现在已经相当好）：
- 不改布局、配色、章节结构、文案里的事实与数字、物理模型。
- 不改 v2 已有的验收保证（见 §4）。
- 不引入框架 / WebGL。JS gzip 仍 ≤ 75 KB（当前 64.9 KB，余量约 10 KB，每加一个 GSAP 插件都要量）。

**本文件明确取代 v2 规格 §3.4 的两条**：「每章只保留一个主菜动画，其余元素静止呈现」和「不做入场动画」。v3 允许并要求角色化的细节动画，但仍然不做「每个卡片淡入上滑」这种通用入场——每一处动画都要有角色或物理上的理由（落地所以挤压、翻滚所以头晕、破云所以眯眼）。

## 1. 公式

### 1.1 技术方案

- **KaTeX，构建时预渲染**。`katex` 是 devDependency。写一个 Vite 插件（`transformIndexHtml`，dev 与 build 都生效），把 `index.html` 里的 `<span data-tex="…">`（行内）和 `<div data-tex="…" data-display>`（独立公式）替换成 `katex.renderToString` 的静态输出（`output: 'htmlAndMathml'`，`strict: false`，`throwOnError: true`——TeX 写错要让构建失败）。**运行时不加载任何 KaTeX JS**；无 JS 时公式照常显示。
- 样式：引入 KaTeX 的 CSS。浏览器只会下载用到的字体文件；验收时确认实际请求的只有 woff2，且不超过 5 个文件。`dist` 里尽量只产出 woff2（做不到就说明）。
- 公式继承所在位置的文字颜色；行内公式与中文基线对齐，字号与正文协调（不要比正文明显大一圈）。
- **不转换的地方**：`<meta name="description">`、所有 `aria-label`、`<title>` 保持纯文本 `v ∝ √d`。KaTeX 自带的 MathML 给读屏用。
- JS 运行时生成的公式文本（如有）不走 KaTeX；第四章「代入当前参数」那一行用普通文字 + Fredoka 等宽数字。

### 1.2 全站统一写法

所有出现 `v ∝ √d` 的可见位置（Hero 结论栏、第二章标题与导语、结尾总结句的「√直径」）统一为行内公式 `v \propto \sqrt{d}`；结尾总结句写成「以与 `\sqrt{d}`（直径的平方根）成正比的速度坠落」。第四章注释里的 `v = k·√d` 改为行内 `v = k\sqrt{d}`。导语里的「三次方 / 平方」保持文字，后面可加行内 `m \propto d^{3}`、`A \propto d^{2}`。

### 1.3 三块新增的独立公式（TeX 原样使用，不要改写物理）

这三块是在「让公式更专业」之外**新增的内容**：只把页面和 `model.ts` 已经说过的话写成式子，不引入新结论。

**第二章 · 为什么是 √d**（放在导语之后、竞速之前或曲线图旁，标题「推导一下」）

```tex
\underbrace{\rho_{\text{冰}}\,\tfrac{\pi}{6}\,d^{3}\,g}_{\text{重力}}
\;=\;
\underbrace{\tfrac{1}{2}\,\rho_{\text{气}}\,C_d\,\tfrac{\pi}{4}\,d^{2}\,v^{2}}_{\text{空气阻力}}
```

```tex
v \;=\; \sqrt{\frac{4\,\rho_{\text{冰}}\,g}{3\,\rho_{\text{气}}\,C_d}}\;\cdot\sqrt{d}\;\;\propto\;\;\sqrt{d}
```

符号说明（一行小字）：`\rho_{\text{冰}}` 冰的密度、`\rho_{\text{气}}` 空气密度、`C_d` 阻力系数、`g` 重力加速度、`d` 直径。**不给 `\rho_{\text{气}}`、`C_d` 代数值**（它们随高度和形状变化，页面只主张比例关系）。

**第三章 · 动能怎么算**（放在「用动能感受一下」标题下、动能条之上）

```tex
E=\tfrac{1}{2}\,m\,v^{2},\qquad m=\rho_{\text{冰}}\cdot\tfrac{\pi}{6}\,d^{3}
```

两行代入（数值已验算，必须原样使用）：

```tex
d=5\,\text{cm}:\quad m\approx 0.059\,\text{kg},\;\; E\approx\tfrac{1}{2}\times 0.059\times 26^{2}\approx 20\,\text{J}
```

```tex
d=8\,\text{cm}:\quad m\approx 0.24\,\text{kg},\;\; E\approx\tfrac{1}{2}\times 0.24\times 37.5^{2}\approx 170\,\text{J}
```

小字说明：「冰的密度取 0.9 g/cm³；速度取速度表范围内的值（5 cm：26 m/s，8 cm：37.5 m/s）。」
验算：0.9×π/6×125 = 58.9 g（即正文的「50 多克」）；½×0.059×26² = 19.9；0.9×π/6×512 = 241 g；½×0.24×37.5² = 168.8。

**第四章 · 模型的三条式子**（放在章末注释处，替换原来那一句的公式部分，「简化教学模型…并非数值天气预报」这句话保留）

```tex
v = k\sqrt{d},\qquad k = 11
```

```tex
d_{\max} = \eta\left(\frac{W}{k}\right)^{2},\qquad \eta = 0.65
```

```tex
d_{\text{落地}} = \max\!\left(0,\; d_{\max} - r\cdot\frac{1000\,H_0}{k\sqrt{d_{\max}}}\right),\qquad r = 0.002\ \text{cm/s}
```

单位说明：`d` 厘米、`v` 与 `W` 米每秒、`H_0` 千米。这三条必须与 `src/lab/model.ts` 完全一致（包括：下落用时按 `d_max` 的落速算，而不是落地直径的落速）。
**加单测**：读 `index.html` 里这三条的 `data-tex`，断言其中的常数等于 `model.ts` 导出的 `K`、`GROWTH_EFF`、`MELT_RATE`——以后改模型常数而忘了改页面时测试会红。

可选（第四章负责人决定）：公式下方一行「代入当前参数」，随滑杆实时显示 `d_max`、下落用时、融化量、落地直径的数值，数字必须来自 `simulate()` 的同一次结果。

### 1.4 公式验收

- 375px 宽下任何独立公式不造成横向滚动（放不下就让该公式块自己横向滚动或换行拆成两行，不能撑破页面）。
- 行内公式不撑高所在行到与相邻行相撞（文字包围盒不相交）。
- 暗底（第二章）与亮底（第三、四章）下公式对比度 ≥ 4.5:1。
- 无 JS（dist）下公式可见；`npm run build` 后 JS gzip 基本不变。

## 2. 雹宝 v2（`src/mascot/mascot.ts`，只由地基步骤修改）

保持现有接口 `createMascot(sizePx, expression)` → `{ el, setExpression }` 不变，所有现有调用不用改也不坏。新增能力：

- **结构**：`.mascot-wrap`（外层，尺寸盒，**永远不被待机动画或反应动画移动/缩放**）→ `.mascot-bob`（内层，待机与反应动画都作用在这里）→ `svg`。
- **更可爱的脸**：腮红（两团淡粉 `#ffb7c5`）、眼睛带高光点、高光弧线保留。
- **待机**：轻微的上下浮动 + 极小的左右摇（周期约 3s）；眨眼（每 3–5 秒一次，每个实例错开相位）。用 CSS keyframes。
- **表情切换**：嘴形用多条 path 叠放、切换时交叉淡入（约 0.18s），不用路径变形插件。安全帽、护目镜出现时带一点回弹的弹入。
- **新表情**（在原五种之外）：`wow`（圆眼圆嘴，惊喜）、`dizzy`（旋涡眼）、`sleepy`（弯眼，放松）。`scared` 加一滴汗；`solemn` 保持素净，不加腮红动画和待机摇摆。
- **一次性反应** `react(kind)`：`'squash'`（落地挤压回弹）、`'hop'`（小跳）、`'shake'`（发抖）、`'pop'`（放大回弹）。作用在 `.mascot-bob` 上，结束后自动复位，可打断重入。
- `prefers-reduced-motion` 下：待机、眨眼、反应全部关闭；表情切换无过渡。
- 尺寸很小时（高度尺上 18–36px、移动端更小）细节不能糊成一团：小尺寸下可以省略腮红和高光。

## 3. 动画规范

### 3.1 共享约定（地基步骤提供）

- **缓动与时长常量**：`src/utils/motion.ts` 导出一组命名缓动（如 `EASE.soft`、`EASE.spring`、`EASE.settle`）与时长，对应的 CSS 自定义属性放 `tokens.css`。新写的动画一律用这组常量，不再各写各的 `power1` / `power2`。
- **在场才动**：提供 `observeInView(el)`（IntersectionObserver，给元素切换 `.in-view` 类）。所有无限循环的 CSS 动画默认 `animation-play-state: paused`，只在 `.in-view` 下运行。离屏不耗电。
- **循环动画只用 CSS keyframes**，不用 GSAP 的 `repeat: -1`（不需要 `gsap.context` 回收，也不占主线程）。一次性的编排动画仍用 GSAP。
- **铁律：待机/循环动画永远不加在「被 GSAP 驱动位移的元素」或「被测量的元素」上**，加在它内部的一层包裹元素上。

### 3.2 各处要加的东西

以下是方向，不是逐帧脚本；负责人要把它做得好看，看截图和录帧自己判断。每一项都要「可爱但不吵」：幅度小、节奏稳、不同时抢戏。

**旅程层（地基步骤）**
- 高度尺上的主角：待机浮动；阶段切换（戴上安全帽、换护目镜、表情变化）时 `pop` 一下；快速滚动时身后出现短短的速度线，停下后消失。
- 云底分界：前后两层云以不同速度随滚动做轻微视差；云朵有极慢的左右漂移。
- Hero 雹胚落到高度尺 10 km：落地 `squash`。

**Hero + 第一章**
- Hero：标题在雹胚落定的那一下有一次很轻的整体「被震到」的回弹；滚动提示的箭头有呼吸感的上下浮动；粒子冰雹大小有层次（近大远小、近快远慢）。
- 第一章：雹胚有一张小脸，翻滚时 `dizzy`，每长大一级 `pop` 并闪一圈冰晶；云体的云团有极慢的「呼吸」；上升气流箭头持续向上流动；洋葱环出现时带回弹；融化的那颗小雹子有表情，过 0℃ 线变成水滴时「啵」地一下。

**第二章 + 第三章**
- 第二章：四颗下落的冰雹有小脸（下落时紧张，落地后 `dizzy` 或松口气），身后有速度线；落地时按个头大小有不同程度的挤压回弹和尘土小团，地面线跟着颤一下（越大越明显）；读数停住时 `pop`。曲线图：圆点落到位时有回弹。
- 第三章：四个实物从左侧滚入并在各自位置停稳（滚动角度与位移匹配，带一点回弹）；2 cm 门槛线画出来；动能条涨到头时有一次「咚」的顿挫，职业投手那根条的末端有一个小棒球飞到位；安全卡里的雹宝戴盔时拍一下头盔（`pop`）。**1986 历史卡保持肃静，不加任何可爱动效。**

**第四章 + 结尾**
- 第四章：舞台上的示范冰雹有小脸（生长时开心、下落时紧张、落地 `dizzy`；rain 结局化成带表情的水滴）；云体呼吸；上升气流箭头流动；落地有回弹和小尘团；结局标签变化时 `pop`；实验室雹宝根据结局换表情（暴雨 `sleepy`、小雹 `happy`、危险冰雹 `wow`、巨雹 `scared`）——这只是表情，不是新的科学陈述；地图上的当前点有柔和的脉冲。
- 结尾：落地时草丛被压弯再弹回；水洼有极慢的涟漪；融化后水洼边长出一株小芽（纯装饰的收尾）；天空里有两三朵极慢漂移的小云，填上现在内容与草地之间的空天；树有轻微的摇摆。

### 3.3 降级

- `prefers-reduced-motion: reduce`：所有新增的循环与细节动画关闭，呈现静态终态。
- 无 JS：新增的静态图形（小脸、小云、小芽等）要么本来就在静态 HTML 里且以终态呈现，要么由 JS 生成且缺了不影响阅读。
- 某章 init 抛错（`data-init-failed`）：新增的预隐藏同样要有失败出口。

## 4. 不能破坏的既有保证（收尾会用 v2 的回归脚本重跑）

1. 高度尺读数：页面顶 10.0 / pin 始 9.5 / pin 终 5.5 / 第二章顶 5.0 / 云底 1.5 / 第四章顶 0.4 / 页面底 0.0。
2. 第一章 pin 期间 `#ch1.offsetHeight ≤ innerHeight`（1440×900、390×844、375×667）；四圈末洋葱环 1/2/3/4；`--hail-scale` 逐级增大。
3. 第二章：球底与地面线间隙 0；读数 35/63/99/144；跨 768 断点 resize 后重赛正确。
4. 第三章：实物直径比 1:2.5:4.5:7.5；动能条宽度比 20:125:170；读数 20/125/170 J。
5. 第四章：示范冰雹云中最大与落地的渲染直径比 = 模型直径比；0℃ 线位置与 H₀ 成正比；地图点击/拖动/触摸与滑杆同步；三个预设结局。**给冰雹加脸不能改变它被测量的那个元素的尺寸。**
6. 结尾：交棒期间逐帧对齐 `getHailRect()`，任一时刻不出现两个雹宝或一个都没有；往回滚恢复。
7. 全页三个视口：文字包围盒不相交、无横向滚动、控制台零错误；无 JS 与 reduced-motion 全文可读；模块失败/迟到/某章抛错的降级路径仍然成立。
8. `npm test` 全过（现有 57 个不能改期望值）；JS gzip ≤ 75 KB；Lighthouse 性能 ≥ 90。
