# 冰雹科普网页 v2 设计规格

日期：2026-11-11
基于：`2026-06-12-hail-website-design.md`（v1 规格仍然有效，本文件只写**变更**；两者冲突时以本文件为准）

## 0. 不变的约束

- 风格：扁平卡通 × 数字具象化。技术栈：Vite + TS（无框架）+ GSAP/ScrollTrigger + SVG + Canvas 2D。不引入 Three.js/WebGL/前端框架。
- 六个章节的顺序、三个核心结论、v1 规格里的全部科普事实与数字**一条都不能丢、不能改值**（见 §8 事实清单）。
- 无 JS 时静态骨架可读全部文案；`prefers-reduced-motion` 下无 pin、无 scrub、无粒子，内容直接呈现。
- 移动端 375px 宽可用，无横向滚动。**每个步骤都要在 1440×900 和 390×844 两个视口验收**。
- 动画只动 `transform` / `opacity`（SVG 属性动画除外）。JS gzip 不超过 75 KB（v1 为 50 KB），字体另计。
- 每个场景模块只暴露 `init(el)`；文案与数据集中在 `content.ts` 或静态 HTML。

## 1. v2 的一个核心想法

**页面本身就是一张大气剖面图，读者跟着同一颗冰雹从 10 km 落到地面。**

v1 里高度尺只是装饰，读数和章节内容对不上。v2 让三件事对齐到同一条「高度」上：

| 文档位置 | 高度 | 内容 |
|---|---|---|
| 页面顶 | 10 km | Hero |
| 第一章 pin 开始 → 结束 | 9.5 → 5.5 km | 在孕育区翻滚长大 |
| 第二章顶 → 底 | 5 → 1.5 km | 坠落、穿过 0℃ 层（4.5 km） |
| 云底分界（第二、三章之间） | 1.5 km | 破云而出，画面由暗转亮 |
| 第三章 | 1.5 → 0.4 km | 危险阈值 |
| 第四章 | 0.4 → 0.1 km | 实验室 |
| 页面底 | 0 km | 落地 |

其余一切保持克制，大胆只用在这一处。

## 2. 旅程层 `src/journey/`（替换 v1 的 `background/sky.ts` 与 `background/ruler.ts`）

### 2.1 高度映射

- `journey.ts` 在所有场景 `init` 之后创建。在 ScrollTrigger 的 `refresh` 事件里重新测量各锚点的滚动位置（必须把第一章 pin 的 spacer 算进去），得到一张「滚动位置 → 高度」的分段线性表。
- 导出纯函数 `altitudeAt(scrollY, anchors)`，放进可单测的文件（不依赖 DOM），并写单测：单调不增、端点为 10 和 0、锚点处取值正确。
- 导出 `temperatureAt(altKm)`：`(4.5 − alt) × 6.5` ℃（0℃ 层在 4.5 km，直减率 6.5 ℃/km；地面约 29℃，10 km 约 −36℃）。同样单测。

### 2.2 天空

- 不再用固定层逐帧改色。天空是 `#app` 上一条**与文档等高**的纵向渐变，色标的像素位置由锚点算出（JS 在 refresh 时写入一个 CSS 自定义属性）。这样每一章背后的颜色只取决于它在文档里的位置，文字对比度是确定的。
- 无 JS 时用百分比色标的静态渐变兜底。
- 色标（按高度）：10 km `#132544` → 5 km `#234a7d` → 1.6 km `#3f6ea6` →（云底分界，急转）→ 1.4 km `#cfe6f7` → 0 km `#eaf5fc`。
- 硬要求：第一、二章内所有正文与表格文字对其背后天空色的对比度 ≥ 4.5:1；第三章起深色文字同样 ≥ 4.5:1。用浏览器实测取色计算，不凭肉眼。

### 2.3 云底分界

第二章与第三章之间放一条通栏 SVG：上方是深色云体的不规则下缘（扁平圆弧拼出的云底），下方露出亮天空。它就是 1.5 km 的云底。纯装饰，`aria-hidden`。

### 2.4 高度尺 + 主角

- 右侧固定高度尺保留，刻度 0–10 km，参照物（民航巡航 10、珠峰 8.8、0℃ 层 4.5、云底 1.5、地面 0）用内联 SVG 小图标，不用 emoji。
- 指示器换成**雹宝本体**：一颗沿尺子下滑的小冰雹，旁边显示两行读数——高度（km，一位小数）和该高度的气温（℃，整数）。
- 主角随旅程变化：Hero 时是小雹胚（约 18px）；第一章 pin 期间随翻滚圈数逐级长到约 36px；第二章起表情为 `scared`；第三章戴安全帽；第四章戴护目镜；到地面变 `happy`。移动端尺寸约为桌面的 0.7。
- 场景通过一个很小的发布接口告诉旅程层当前阶段（例如 `setStage('grow', progress)`），旅程层不反向依赖场景。
- `aria-hidden="true"`，纯视觉。

## 3. 视觉系统

### 3.1 色彩（`tokens.css`）

| 名称 | 值 | 用途 |
|---|---|---|
| 夜云 | `#132544` | 天空顶、深色卡片 |
| 风暴蓝 | `#234a7d` | 云体、深色面 |
| 冰白 | `#eef8ff` | 冰雹填充、暗底文字 |
| 冰线 | `#9fcbe8` | 冰雹描边、暗底辅线 |
| 警示黄 | `#ffd23f` | 唯一的强调色：数字读数、主角高亮 |
| 危险红 | `#e5484d` | 只用于危险等级的最高档 |
| 草地绿 | `#6fbf73` | 地面、安全档 |
| 墨蓝 | `#10233f` | 亮底文字 |

危险色带四档：草地绿 → 警示黄 → `#f2994a` → 危险红。

### 3.2 字体

- 数字与拉丁字符：**Fredoka**（可变字重，自托管，`@fontsource-variable/fredoka`，只加载 latin 子集）。圆头数字和冰雹的圆是一家人，数字是这个页面的主角。
- 中文：系统字体栈。标题优先 `'Yuanti SC'`（macOS 圆体），回退 `PingFang SC` / `Hiragino Sans GB` / `Microsoft YaHei` / `Noto Sans CJK SC`。正文不用圆体。
- 字号阶梯（比例 1.25）：正文 17 → 小标题 21 → 章标题 clamp(30, 4.4vw, 46) → Hero 标题 clamp(44, 8vw, 96)。正文行宽不超过 38 个汉字。
- 所有会跳动的数字用 `font-variant-numeric: tabular-nums`。

### 3.3 插画规则（所有 SVG 共用）

- 纯色填充，不用渐变、不用投影滤镜。冰雹：冰白填充 + 冰线描边 3px。线端与转角一律圆头。
- 图里的图标一律内联 SVG，不用 emoji。正文句子里原有的 emoji 可以删掉或换成图标，不新增。
- 每张图都要有可读的 `aria-label` 或 `<title>`；纯装饰加 `aria-hidden`。

### 3.4 去掉的模板痕迹

- Hero 顶部的宽字距英文小标签删掉。
- 「第一章」这类章节标记保留（内容确实是序列），但不再用 0.4em 宽字距 + 半透明。
- 三张结论卡不再是三个等大的圆角半透明卡片（见 §4 Hero）。
- 不做「每个卡片滚入时淡入上滑」的通用入场。每章只保留一个主菜动画，其余元素静止呈现。

### 3.5 布局

- 桌面：内容列左对齐，最大宽 1080px，右侧给高度尺留出 96px 不放内容。
- 章节之间的留白统一为 `clamp(72px, 14vh, 160px)`，去掉 v1 里章节内部的大段空白（每章 `min-height:100vh` + 垂直居中导致的）。只有 Hero、第一章（pin）、结尾是整屏。

## 4. 各章变更

### Hero

- 标题左对齐、占满内容列。雹胚从屏幕上沿落到高度尺的 10 km 处停住——这就是之后一路陪读者下落的那颗。
- 三个结论改为标题下的一行三栏，无卡片边框，栏间用细竖线分隔；数字用 Fredoka、警示黄，下面一行说明。移动端竖排。
- Canvas 粒子保留但降到约一半密度，不遮挡标题。

### 第一章 · 生成高度

- pin 的舞台必须整屏放得下：桌面两栏（左文字，右 SVG），移动端上下排（SVG 高度不超过 46vh）。章节高度 = 视口高度，实测 `offsetHeight ≤ innerHeight`。
- 重画积雨云剖面：有砧状云顶的完整积雨云；图内左侧有 0–12 km 的高度轴和对应气温刻度；0℃ 线（4.5 km）与孕育区（−10℃ ～ −30℃，约 5–10 km）按轴的真实比例摆放；上升气流用一组向上流动的箭头表示。
- 主菜「翻滚生长」：雹胚沿一条闭合环形轨迹运动（GSAP MotionPathPlugin），共四圈；每圈雹胚长大一级，右侧大号「洋葱剖面」同步多一环，环的填充在透明冰与不透明冰之间交替。
- 左栏文字随时间线分四步切换（一次只显示一步），最后一步是融化伏笔：太小的雹子过 0℃ 层化成雨——图里一颗小雹子落过 0℃ 线后变成水滴。
- 标签之间不得重叠（实测包围盒）。

### 第二章 · 落地速度

- 竞速保留。每条赛道加一条参照线：城市行车 60 km/h、高速公路 120 km/h，让 km/h 有可比对象。
- 新增一张 SVG 曲线图：横轴直径（0–8 cm），纵轴速度（0–45 m/s），滚动进入时描出 `v ∝ √d` 曲线，四个尺寸点依次落在曲线附近并标出参照物。四个点用速度表的真实值（`raceLanes`），曲线用 `K·√d`——点不完全在线上是对的，图注说明「曲线是简化规律，圆点是各尺寸的典型值」。
- 速度表保留为真实 `<table>`，样式重做；移动端不横向溢出。

### 第三章 · 危险阈值

- 尺寸阶梯的四个圆点换成四个等比例的 SVG 实物（黄豆、乒乓球、高尔夫球、垒球），下方色带对应四档危险色。标注 2 cm 门槛线。
- 动能条保留，改成同一把刻度尺上的三根条：5 cm 冰雹 20 J、职业投手快速球（约 150 km/h 的棒球，约 125 J）、8 cm 冰雹 170 J。这样「超过职业投手快速球」一眼可见。
- 1986 孟加拉卡片保留压暗与默哀。
- 安全卡两张保留，emoji 换成 §3.3 的图标。
- 应季提醒改为不过期的写法：「关东地区的冰雹多发在 5–7 月的午后——初夏强对流最活跃的时候。」

### 第四章 · 实验室

- 舞台改为一张竖向剖面图（SVG 或 Canvas）：上方云体、一条随 H₀ 滑杆上下移动并标注高度的 0℃ 线、数量与速度随 W 变化的上升气流箭头；一颗示范冰雹在云里长到「云中最大雹径」，然后下落，过 0℃ 线后逐渐缩小，落地时的大小就是「落地直径」（rain 结局时在半空变成雨滴）。循环播放，参数变化时立刻重启。
- 新增「结局地图」：一张 W（横轴 5–50）× H₀（纵轴 2–6）的色块图，每格颜色是该参数组合下的结局（由 `simulate` 算出），当前参数处有一个圆点。点击或拖动地图可同时设置两个参数，与滑杆双向同步。三个预设在地图上标出位置。
- 滑杆、预设按钮、三个数值读数保留。物理模型 `src/lab/model.ts` **不改**，现有 11 个单测必须原样通过。
- 四种结局的 emoji 换成内联 SVG 图标，文字标签不变。

### 结尾

- 一条通栏的草地地面（扁平圆弧草丛 + 两三个简单参照物，如小房子、树）。主角冰雹从高度尺离开、落到草地上、融化成水洼。
- 三个结论的回顾用与 Hero 相同的三栏样式。
- 新增「数据来源」两条：NOAA NSSL《Severe Weather 101: Hail》（https://www.nssl.noaa.gov/education/svrwx101/hail/）；WMO 天气与气候极端事件档案（最重冰雹，1.02 kg，孟加拉国戈帕尔甘尼，1986-04-14）。

## 6. 验收（每步都用浏览器实测数字判定）

- `npm test`、`npm run build` 通过。
- 1440×900 与 390×844：无横向滚动（`scrollWidth ≤ innerWidth`）；控制台零错误。
- 高度尺读数在各锚点处与 §1 的表一致（±0.2 km）。
- 文字对比度见 §2.2。
- 第一章 pin 时 `offsetHeight ≤ innerHeight`；标签包围盒两两不相交。
- 关闭 JS：全部文案可读。`prefers-reduced-motion`：无 pin、无粒子、内容完整。
- Lighthouse 性能 ≥ 90。

## 8. 事实清单（v2 必须原样保留，收尾时逐条核对）

1. 冰雹生成高度 5–10 km；孕育区 −10℃ ～ −30℃
2. 云底 1–2 km
3. 0℃ 层约 4–5 km；太小的雹子过 0℃ 层融化成雨
4. 每翻滚一次裹一层冰，切开像洋葱；上升气流越强托住的冰雹越大
5. 珠峰 8.8 km；民航巡航 10 km
6. v ∝ √d；质量随 d³、迎风面积随 d²
7. 1 cm：黄豆～指甲，~10 m/s（35 km/h），砸着疼基本无害
8. 2–3 cm：硬币～乒乓球，15–20 m/s（50–70 km/h），可致淤青、砸伤眼睛
9. 4–5 cm：高尔夫球，25–30 m/s（约 100 km/h），头部裂伤、脑震荡风险
10. 7–8 cm：棒球～垒球，35–45 m/s（130–160 km/h），可能致命
11. 数值受形状、密度、风影响，为典型范围
12. 许多国家以 2–2.5 cm 为强对流灾害预警门槛
13. 5 cm ≈ 50 多克，落地动能约 20 J ≈ 棒球以 60 km/h 砸中
14. 8 cm 约 170 J，超过职业投手快速球，命中头部足以致命
15. 1986 年孟加拉国雹灾，单颗近 1 kg，近百人遇难
16. 硬币大小→别在外面晃；高尔夫球大小→立刻进坚固掩体、远离窗户（玻璃二次伤害）
17. 关东地区冰雹高发于初夏午后
18. 实验室两个参数：上升气流强度 5–50 m/s、0℃ 层高度 2–6 km；四种结局；三个预设 (12, 5) / (30, 3.5) / (50, 3)
19. 气象台用这两个参数预报冰雹；页面注明「简化教学模型」
20. 结尾回顾三个结论：5–10 km / 10–40+ m/s / ⌀2 cm
