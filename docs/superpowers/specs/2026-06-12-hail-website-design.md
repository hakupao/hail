# 冰雹科普网页设计规格

日期：2026-06-12
状态：待用户审阅

## 1. 项目概述

一个纯前端、无后端的单页滚动网页，主题是科普"冰雹"这一自然现象。核心诉求：**用动画和简单图画把数字具象化**——动效与特效是第一公民，科普内容围绕三个核心结论展开。

成功标准：

- 读者滚完一遍页面，能记住三个数字结论（生成高度、落地速度规律、危险阈值）
- 每章有一个"主菜"动画，把抽象数字翻译成直觉感受
- 桌面端滚动全程流畅（60fps 目标），移动端可用
- 纯静态产物，`vite build` 后可托管在任何静态服务器

## 2. 定位与视觉风格

- **定位**：科普向，但以动效表现力为卖点（数字具象化 > 文字阅读）
- **风格**：扁平化 + 卡通化，两种口味的结合：
  - **主体——扁平信息图风**（The Pudding 味）：几何图形、大号数字、精准比例尺，动效以数据演绎为主（数字滚动、轨迹描线、比例尺缩放、图表生长）
  - **串场——吉祥物"雹宝"**（Kurzgesagt 味）：一颗有表情的拟人化冰雹，负责章节过渡、情绪引导和安全演示，**不抢数据的戏**
- **色彩弧线**：天空背景色随滚动连续渐变——云内深蓝（#1a2b4a 一带）→ 破云 → 地面亮蓝（#e9f4fb 一带），隐喻一颗冰雹的下坠旅程
- 文案语言：中文为主，英文仅作装饰性点缀

## 3. 页面架构：双层混合

- **背景层**（贯穿全站，与章节零耦合）：
  - 天空渐变色：监听全局滚动进度 0→1，连续插值颜色
  - **高度尺**：页面右侧纵向刻度，随滚动从 10 km 降到 0 m，参照物标记（民航巡航 10 km、珠峰 8.8 km、0℃ 层 4–5 km、云底 1–2 km）在对应章节亮起
- **前景层**：六个章节模块，各自独立实现、独立 ScrollTrigger，章节间由背景层缝合出"一直在下坠"的整体感

### 3.1 章节分镜（滚动顺序，全长约 8–10 屏）

**HERO · 开场**

- 标题《一颗冰雹的诞生与坠落》（实现时可微调文案），雹宝从屏幕上方砸进标题旁
- **三个结论先行**：三张数字卡片（5–10 km / 10–40+ m/s / ⌀2 cm 起步伤人），数字滚动跳出
- 向下滚动提示；Canvas 粒子冰雹雨做氛围

**第一章 · 生成高度 5–10 km**

- 积雨云剖面图随滚动徐徐展开：云底 1–2 km，孕育区 −10℃～−30℃（约 5–10 km）高亮
- 主菜动画——**翻滚生长**：雹胚被上升气流反复托起又下落，每翻滚一圈裹一层冰，旁边"洋葱剖面"同步多一环
- 参照物：珠峰 8.8 km、民航巡航 10 km 在高度尺上点亮
- 收尾梗：太小的雹子过 0℃ 层（4–5 km）半路融化成雨——雹宝的小同伴"滴"地变成水滴（为第四章埋伏笔）

**第二章 · 坠落速度 v ∝ √d**

- 主菜动画——**坠落竞速**：四颗冰雹同时释放，各按终端速度下坠，配速度表指针 + km/h 数字狂跳
- 物理一句话：质量随 d³ 增长、迎风面积随 d² 增长 → 越大越快，公式 `v ∝ √d` 描线写出
- 速度对照表做成随滚动逐行点亮的动画表格：

| 直径 | 参照物 | 落地速度 | 危险程度 |
|---|---|---|---|
| 1 cm | 黄豆～指甲 | ~10 m/s（35 km/h） | 砸着疼，基本无害 |
| 2–3 cm | 硬币～乒乓球 | 15–20 m/s（50–70 km/h） | 可致淤青、砸伤眼睛 |
| 4–5 cm | 高尔夫球 | 25–30 m/s（约 100 km/h） | 头部裂伤、脑震荡风险 |
| 7–8 cm | 棒球～垒球 | 35–45 m/s（130–160 km/h） | 可能致命 |

（注：受形状、密度、风影响，为典型范围）

**第三章 · 危险阈值 ⌀2 cm 起步**

- 等比尺寸阶梯：硬币→乒乓→高尔夫→垒球逐个滚入，危险色带 绿→黄→橙→红 跟着升级；点明许多国家以 2–2.5 cm 为强对流灾害预警门槛
- **动能具象化**：5 cm ≈ 50 多克、落地动能约 20 J ≈ 棒球以 60 km/h 砸中你（卡通棒球手演示）；8 cm 可达 170 J 上下，超过职业投手快速球，直接命中头部足以致命；能量条动画上涨
- 历史卡片：1986 年孟加拉国雹灾，单颗近 1 kg，近百人遇难（整体色调沉下来，雹宝摘帽默哀）
- 实用判断卡：**硬币大小→别在外面晃；高尔夫球大小→立刻找坚固掩体**，并远离窗户（玻璃二次伤害常见）——雹宝戴安全帽演示
- 应季小贴士：六月正值关东地区冰雹高发季（强对流多发于初夏午后）

**第四章 · 冰雹实验室 🧪（交互）**

- 两个滑杆：**上升气流强度 W**（5–50 m/s）、**0℃层高度 H₀**（2–6 km）
- 实时输出四种结局 + 最大雹径 + 落地速度，云和降水动画实时变化：
  ☔ 只下暴雨 / 🌨 小雹半路融化 / 🧊 冰雹落地 / 💀 巨雹警报
- 预设按钮：「典型雷阵雨」(12, 5)、「强对流冰雹日」(30, 3.5)、「1986 孟加拉」(50, 3)
- 穿白大褂的雹宝当实验室助手，解说气象台正是用这两个参数预报冰雹
- 页面注明"简化教学模型"

**结尾 · 落地**

- 雹宝安全落在草地上慢慢融化成小水洼（微笑），三个结论数字卡片回顾定格

## 4. 技术栈

- **Vite + TypeScript**，无前端框架（单页项目，模块化靠 TS 自身）
- **GSAP + ScrollTrigger**：所有滚动驱动动画的总指挥
- **SVG**：插画、图表、雹宝角色（扁平矢量 + GSAP 属性动画）
- **Canvas 2D**：粒子密集型特效（Hero 冰雹雨、实验室实时降水）
- 不使用 Three.js/WebGL（扁平风格用不上，省体积）

## 5. 代码结构

```
hail/
├── index.html              # 全部章节的静态骨架（无 JS 时仍可读全部文案）
├── src/
│   ├── main.ts              # 入口：注册背景层 + 各场景
│   ├── styles/              # 设计令牌（颜色/字号/间距）+ 各章样式
│   ├── background/          # 贯穿层：天空渐变 + 高度尺
│   ├── scenes/              # hero / ch1-height / ch2-speed / ch3-danger / ch4-lab / ending
│   ├── mascot/              # 雹宝：SVG 模板 + 表情库 + 动作库
│   ├── lab/                 # 实验室物理模型（纯函数）+ 滑杆 UI
│   └── utils/               # 数字滚动、Canvas 帮手等
└── public/                  # 字体等静态资源
```

接口约定：

- 每个场景模块只暴露 `init(el): void`，内部自建 ScrollTrigger、销毁自理；改一章不碰其他章
- 背景层独立监听全局滚动进度（0→1 映射到 10 km→0 m 与色彩弧线），与各章零耦合
- 文案、表格数据、参照物数据集中在 `content.ts`，改数字不动动画代码
- 实验室模型与 UI 分离：`simulate(W, H₀) → { 结局类型, 最大雹径, 落地速度 }`

## 6. 实验室物理模型（简化教学模型）

纯函数，输入上升气流 W（m/s）与 0℃层高度 H₀（km）：

1. **终端速度**：`v = k·√d`，k 按第二章速度表校准（约 11–13，d 单位 cm、v 单位 m/s）
2. **最大雹径**：上升气流托不住时冰雹坠落，`d_max = (W/k)²`
3. **融化损耗**：落地前在暖层中的时间 ≈ H₀/v；损耗与暖层厚度成正比、与下落速度成反比——小雹 + 高 0℃ 层 → 半路化成雨
4. **结局判定**（按融化后落地直径）：< 0.5 cm ☔ 暴雨 / 0.5–2 cm 🌨 小雹 / 2–5 cm 🧊 危险冰雹 / > 5 cm 💀 巨雹警报

校准硬标准：模型输出必须与第二章速度表自洽（四个尺寸点速度误差 < 15%）。

## 7. 性能、响应式与降级

- 动画只动 `transform` / `opacity`；Canvas 粒子限额：桌面 ~300、移动 ~120
- 各章懒初始化（不滚到不干活）；全矢量资源，页面体积目标 < 500 KB（字体另计）
- 帧率目标：桌面 60fps，中端手机 ≥ 30fps
- 移动端（< 768px）：高度尺收窄成色带、竞速改纵向轨道、实验室滑杆竖排
- `prefers-reduced-motion`：scrub 动画退化为静态分步 + 淡入，粒子层关闭
- 浏览器支持：现代 evergreen 浏览器（约 2023+ 的 Chrome/Edge/Firefox/Safari），不支持 IE

## 8. 验证方式

- **vitest 单测**实验室纯函数：极弱气流必为暴雨；速度表四点误差 < 15%；三个预设结局正确（典型雷阵雨→☔ 暴雨；强对流冰雹日→🧊 危险冰雹；1986 孟加拉→💀 巨雹警报）
- `tsc` 与 `vite build` 零报错
- Chrome DevTools 走查：逐章截图核对视觉、console 零错误、性能 trace 看帧率
- Lighthouse 性能分 ≥ 90

## 9. 范围外（本版不做）

- 音效
- 部署上线（build 产物可托管任意静态服务，后续再说）
- 多语言 / 英文版
- "为什么有的雷暴下冰雹"之外的更多气象学内容（如雷达回波、防雹作业）
