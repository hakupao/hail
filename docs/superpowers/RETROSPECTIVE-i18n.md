# 复盘：i18n 三语（2026-11-24）

## 做了什么

- 中文 / 日本語 / English 三语，加一个「跟随系统」选项：系统首选语言是中文系 → 中文、日文 → 日文，其余一律英文。
- 中文继续直接写在 `index.html` 里，作为源文本和无 JS 时的兜底。运行时在各章 init 之前换好文案，切换语言时刷新页面。
- 公式里带汉字的（ρ冰、重力、空气阻力、d落地）每种语言各预渲染一份，运行时只留当前语言那份。

## 保留下来的做法

- **先换文案、再 init：** 跟 GSAP 的测量和 pin 不冲突，切换时直接刷新，不用写重新初始化的代码。
- **键值对齐交给单测：** 每个键都有译文、没有多余的键、`{slot}` 对得上、三份公式只差 `\text{…}`。新增文案忘了翻译，测试会红。
- **整页检查用 reduced-motion：** 关掉 pin 和动画，直接对每章截图、查横向溢出。

## 必须补上的缺口

- **改写率 100%，按规则 A 做了抽检：** 另起一个 critic agent 逐键核对了日文和英文（全量，不是抽样）。结果：数字、单位、物理含义和避险建议都没有错；有 22 处措辞或术语不统一，采纳 21 处，没采纳的那处见下。
- **审阅时发现的中文原文问题：** 第三章写「单颗冰雹重**近** 1 公斤」，来源写的是 1.02 kg，两处矛盾。中文原文没改，日文和英文写成「约 1 kg」，留给作者定。
- **长度敏感的位置：** SVG 胶囊标签、赛道名、标题里的「5–10 km」，各语言要单独看。已经用 `data-i18n-attr` 给每种语言设了宽度，并加了 `&nbsp;` / `<wbr>`。

## 关键决策复盘

- **运行时替换，而不是按语言生成多个页面（/en/、/ja/）：** 多页面的好处是无 JS 时也能看到外语，但要改 Vite 的多入口和相对资源路径。站点本身靠 JS 动画，取舍下选了运行时替换，加 `?lang=` 作为分享链接。
- **没采纳的那条建议：** 审阅建议把日文比例尺标签改成「ひょうの大きさ比較」，但它在 SVG 里放不下，用了「縮尺」。
